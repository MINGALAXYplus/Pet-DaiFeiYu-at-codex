# 小鲸女仆（Codex Pets）

本仓库保存 2026-10-28 创建并选用的 ChatGPT Pet「小鲸女仆」的最终交付记录。

- 角色：蓝发蓝眸、鲸鱼侧鳍、蕾丝女仆装和鲸鱼围裙；安静聪明、认真体贴、略带害羞。
- 动画：9 种标准动作，共 57 帧；16 向视线，共 16 帧；Pets v2 图集。

这是一份角色素材和验证归档。Pets 接口支持外观、动作、描述和选用，但不提供实时额度气泡注入，因此没有实现常驻剩余额度显示。dsh-pet 仅作功能参考，未移植其动画素材。

细节限制：左跑动作中的小鲸图案方向与原始参考存在轻微差异；接近水平的视线变化较轻。未宣称像素级复刻。
